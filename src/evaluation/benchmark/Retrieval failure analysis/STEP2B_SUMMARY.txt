STEP 2B — RETRIEVAL FAILURE ANALYSIS

Purpose
-------
This folder contains the retrieval-problem subset extracted from the frozen
Step 2A row-level retrieval evaluation.

Source
------
01_row_level_retrieval_evaluation.csv

Scope
-----
All questions whose original retrieval assessment is PARTIAL or NO.

Counts
------
Total evaluation questions: 132
Retrieval problems: 39
PARTIAL: 12
NO: 27

Files
-----
01_all_retrieval_problems.csv
    Complete row-level subset of all PARTIAL/NO retrieval cases.

02_retrieval_problems_by_document.csv
    Aggregated count of retrieval problems by source document.

03_retrieval_problems_for_manual_review.csv
    Reduced, clean file containing the information needed for manual
    inspection of each retrieval problem.

STEP2B is an analysis/triage stage. It does not change the frozen baseline
results and does not rerun the RAG pipeline.

Next step
---------
Manually inspect these retrieval-problem rows and determine the nature of
each failure (for example: missed evidence, wrong page, insufficient
retrieval, or other retrieval-related issue) before moving to deeper
failure analysis.
